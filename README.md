# Dishwasher Troubleshooting Expert System

A rule-based Expert System developed using **SWI-Prolog** to diagnose and troubleshoot common dishwasher problems[cite: 7, 8]. The system utilizes a domain-specific knowledge base of facts and logical inference rules to provide automated recommendations[cite: 8].

## 🚀 Features
* **Knowledge Representation:** Stores facts regarding specific dishwasher error conditions (e.g., startup failures, low water level, dirty dishes)[cite: 8].
* **Logical Inference Engine:** Applies expert rules to link symptoms with appropriate corrective actions[cite: 8].
* **Dynamic Knowledge Base Management:** Uses dynamic predicates to retract resolved issues from memory during execution[cite: 10, 13].
